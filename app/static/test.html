实验性

说明

开发中的新效果先放在这个页面验证,确认后再合入正式页面。当前进行中的试验: ① 总览页 2D 俯视车模重设计(解决「像蛤蟆」:现款宽高比约 2.0,真实 Model Y 俯视约 2.47,且轮胎块肥大外凸); ② 控制页 3D 车模原型(Three.js 程序化建模,点击车身部位触发对应指令区域)。

① 总览车模 · 2D 方案对比

三个方案共用同一副「写实比例」轮廓(长宽比 2.48,轮胎收窄贴合车身),差别在细节与质感; 均演示了正式功能叠加层:前风挡电量填充(65%)、玻璃顶能量环(未充/驻车/哨兵/行驶/剩余)、胎压读数。

现款(对照)

宽高比 2.0 偏宽 · 轮胎块肥大外凸
翼子板鼓出明显 →「蛤蟆」感来源

方案 A · 写实线条

扁平风格 + 完整车身细节
大灯 / 尾灯条 / 门把手 / 充电口

方案 B · 光影质感

同轮廓 + 车身径向光影 / 玻璃渐变
地面投影 / 大灯微光,接近渲染图

方案 C · 极简纯净

只留轮廓 + 玻璃 + 能量环
无灯组/门把手等装饰,最干净

② 控制页 · 3D 车模原型

Three.js 程序化建模的风格化 Model Y(无外部模型文件,库已本地化 /vendor/,无版权问题)。 点击车身部位 = 控制页指令区域:车头=前备箱、前风挡=哨兵、车顶=空调、左身=车锁、右身=车窗、 左后翼子板=充电口、车尾=后备箱。再次点击切换开/关(绿色发光=开)。
